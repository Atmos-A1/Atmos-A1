## 🚀 Featured Projects

I use personal projects to turn concepts into practical experience. Each project helps me explore different parts of software development, from user interfaces and databases to application architecture and testing.

### 🎧 1. Audiobook Companion

**A local-first audiobook player and synchronized reading application for Linux Mint.**

I'm building an audiobook experience that combines Apple Music-inspired live text highlighting with Spotify-inspired library organization.

**What I'm working on:**
- Synchronizing audiobook narration with individual words and sentences.
- Managing audiobook libraries, collections, chapters, and playback progress.
- Supporting audiobook files and subtitle formats.
- Building a customizable reading experience with themes and typography.
- Using SQLite for local persistence.
- Testing functionality and packaging the application for Linux.

**Technologies:** Python, PySide6, SQLite, mpv, pytest, Ruff, Linux.

🔗 [View Repository](https://github.com/Atmos-A1/AudioBookPlayer)

---

### 📌 2. NoticeBoard — Class Announcement System

**A web application for managing class announcements and student access.**

This project explores how authentication, database rules, and application-level permissions can work together to support a structured educational noticeboard.

**Features include:**
- Student and administrator workflows.
- Announcement creation, publishing, archiving, and pinning.
- Registration invitations and approval workflows.
- Search and category filtering.
- Database-level access control.
- Input validation and automated testing.

**Technologies:** Next.js, React, TypeScript, Tailwind CSS, Supabase, PostgreSQL, Vitest.

🔗 [View Repository](https://github.com/Atmos-A1/NoticeBoardProject)

### ⌨️ 3. TypingTutor

**A typing practice application focused on accuracy, speed, and consistent improvement.**

I'm exploring how to build a reliable typing application, starting with its session engine and expanding toward a complete desktop experience.

**Areas of development:**
- Typing-session state management.
- Character tracking and mistake counting.
- Accuracy calculations and session completion.
- Unicode-aware input handling.
- Automated tests and continuous integration.
- A roadmap toward adaptive lessons and progress tracking.

**Technologies:** Rust, Cargo, Rust testing tools, Clippy, GitHub Actions, Linux.

🔗 [View Repository](https://github.com/Atmos-A1/TypingTutor)
